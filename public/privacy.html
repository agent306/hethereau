Privacy Policy

Effective Date: November 19, 2026 · App: Hethereau (https://hethereau.pages.dev)

Hethereau is an unofficial, open-source pull tracker for Neverness to Everness. Your privacy is a core design goal: Hethereau runs entirely client-side in your browser and operates no application backend or user database.

1. Data Stored Locally

When you import pull history or create profiles in Hethereau, your pull records and tracker preferences are stored locally in your browser's IndexedDB and localStorage. None of this data is transmitted to Hethereau's servers.

2. Optional Google Drive Sync & Google User Data

If you choose to sign in with Google to enable cloud backup across devices, Hethereau requests only the following minimal, non-sensitive Google OAuth scopes:

  • https://www.googleapis.com/auth/drive.appdata — Allows Hethereau to create, read, and update a single backup file (hethereau-sync-v1.json) inside its own hidden Google Drive application data folder (appDataFolder). Hethereau cannot view, read, list, or modify any other files or folders in your Google Drive.
  • https://www.googleapis.com/auth/userinfo.email — Used solely to display your signed-in email address in the interface so you can confirm which Google account is connected.

OAuth access tokens stay strictly in your browser memory for your active session and are never logged, sent to any third-party server, or stored on a backend. Sync requests go directly from your browser to Google's Drive API.

3. Google API Services User Data Policy

Hethereau's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements. We do not sell, rent, share, or use Google user data for advertising, analytics, profiling, or AI/ML model training.

4. Optional Anonymized Global Statistics

Before importing pull history, you may choose whether to contribute anonymized pull statistics to Hethereau's community Global Stats (enabled by default; uncheck the box before importing to remain 100% local with zero network requests). When opted in, only deduplicated record hashes, banner/item IDs, timestamps, and an anonymous random browser contributor ID are transmitted to Cloudflare Workers & Durable Objects. No Google account email, game UID, or raw IP address is stored (rate limiting uses an irreversible daily-rotating salted hash).

5. Local Import Script

The optional Windows PowerShell import script (/import-nte.ps1) runs locally on your machine to decode pull history into sanitized JSON on your clipboard. It removes network addresses and session identifiers before export and never uploads data automatically.

6. Data Retention & Deletion

  • Local browser data: You can clear any profile's pulls at any time from Profiles & Cloud Sync or by clearing site data in your browser.
  • Google Drive sync data: You can disconnect Google Drive Sync inside Hethereau at any time, delete Hethereau's hidden app data via Google Drive → Settings → Manage Apps, and revoke OAuth access at myaccount.google.com/permissions .

7. Hosting & Third-Party Infrastructure

Hethereau is served as a static website via Cloudflare Pages, which may process standard HTTP request logs (such as IP address and requested asset path) according to Cloudflare's privacy policy. Fonts are loaded from Google Fonts.

8. Source Code & Contact

Hethereau is open source. You can inspect the complete source code or report privacy questions via GitHub Issues at github.com/agent306/hethereau .

Hethereau is an unofficial fan tool and is not affiliated with Hotta Studio or Perfect World Games.
